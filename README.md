# camino-legal

Páginas legales de **Camino**, la aplicación de entrenamiento de calistenia
(`com.camino.calistenia`).

Existe sólo para que la política de privacidad tenga una URL pública, que es un
requisito de la ficha de Google Play. No contiene código de la aplicación.

| Página | Archivo |
|---|---|
| Política de privacidad (español) | [`index.html`](index.html) |
| Privacy policy (English) | [`en.html`](en.html) |

Se publica con GitHub Pages desde la rama `main`, en la raíz.
